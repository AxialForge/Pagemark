# Documentation

Every PDF, Word (.docx) and other generated document for this project is saved in this folder: manuals, audit and readiness reports, release notes, overviews.

Files are named `<Document name> Rev <major.minor>` (for example `Audit Report Rev 1.2.pdf`). Rebuilding a report makes the next revision; the older one is kept.

Source Markdown and the build scripts stay where the project keeps them (usually `docs/`).
