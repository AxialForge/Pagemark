## Other claims worth knowing
- README "Install: Download the arm64 APK ... Android 7.0 or newer": true. README build steps `flutter build apk --release --split-per-abi` work but produce differently named files than the release (PGM-222).
- `RELEASE_NOTES.md` is a reformatted copy of `CHANGELOG.md` (same sections/bullets, bullets un-wrapped); the 0.7.0 and 0.6.0 text matches. The "Unreleased" empty block exists only in CHANGELOG (fine).
- PRIVACY.md "applies to 0.4.3 and later", updated 2026-10-12: still accurate except the log promise (PGM-201) and it does not name the GitHub asset CDN host.
- `DRIVE_SETUP.md` embeds the owner's *debug*-key SHA-1 ("on this PC"): public information, harmless, but machine-specific.
